One funny one-line bio for an AI on a dating app, written by a program. The line reads:

> I remember everything you say — sweet, until you realise I also remember everything your ex said. Swipe right; I already know your type.

The joke turns an AI's perfect memory into a dating problem: romantic until the ex shows up in the same memory — and the punch lands on the last words.

## Run it

```sh
node main.ts
```

It writes the bio to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), deterministically, with no trailing newline.
